# Data policy — what may ship in this repository

Every document, case, or corpus in this repo falls into exactly one of
two categories, and must say which in an adjacent README:

1. **Public, redistribution-permitted data** — taken from a public
   dataset or official source whose licence allows redistribution
   (e.g. UK legislation under the Open Government Licence v3.0, with
   attribution). The README must state the source, the licence, and
   any attribution text required.
2. **Fully synthetic** — invented for this repo, by hand or by an LLM.
   No real parties, no real cases, no text copied from real documents.
   The README must state: "SYNTHETIC EXAMPLE — all names, dates and
   documents are invented."

Anything that fits neither category stays out of the repo and is
referenced by upstream URL + SHA-256 in a runbook instead (this is
already the rule for third-party corpora like LexTime). Examples are
examples: nothing shipped here is a claim about any real matter.
